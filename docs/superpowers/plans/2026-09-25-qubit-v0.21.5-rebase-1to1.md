# Qubit v0.21.5 (`69948c0057`) 1:1 Rebase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the deterministic rebrand of upstream Hermes `69948c0057` as Qubit's vendored runtime, preserving the Qubit overlay and brand, so Qubit reaches behavioural parity for the shared surface and every capability is voice-commandable.

**Architecture:** Third-party source is rebranded by an explicit-token transform, not hand-ported. We extend the transform, generate a candidate `qubit_runtime/` from the exact pinned source, then 3-way merge it with the current Qubit tree (base = engine(v0.21.4), ours = engine(v0.21.5), theirs = current Qubit), re-apply the overlay-only files, curated path-renames, and fork patches, then regenerate artifacts and verify.

**Tech Stack:** Python 3.12 (venv at `.venv`), `scripts/qubit_rebrand.py` + `scripts/qubit_debrand.py` (deterministic, idempotent), GNU diff/git for the merge, pytest, the Tier-0 audit harness `scripts/forensic_audit/`, Vite/tsc + Vitest for the frontend.

**Spec:** `docs/QUBIT_1TO1_ROOT_CAUSES.md`, `docs/QUBIT_OWNER_AMENDMENT_2026-09-25_PIN_AND_1TO1.md`, `docs/generated/audit/V0_21_5_REBASE_2026-09-25.json`, and the Tier-1 plans `/tmp/qubit-1to1-*/plans/B1..B4`.

## Review Focus

1. **Dynamic-lookup conflicts.** A merge can resolve cleanly yet leave a `getattr`/registry/dict-key string pointing at a pre-rename name; the tests that catch this are import + resolve probes, not diff cleanliness.
2. **Engine token gaps.** New upstream modules whose name is not in the token map (already bit us: `hermes_state_health`, `hermes_yaml`); the test is a whole-tree import smoke + a zero-legacy-import assertion.
3. **Overlay regressions re-introduced by new upstream code.** `voicebridge/qubit_compat.py` handlers may shadow/override new upstream routes; the test is the route-owner/E2E audit.
4. **Voice-path gaps.** A new 0.21.5 capability present but not commandable; the test is the voice-coverage report resolving a live intent to a backend.
5. **Generated-artifact drift.** The rebase invalidates `docs/generated/*`; the test is `--check` determinism on each generator (byte-identical ×2).
