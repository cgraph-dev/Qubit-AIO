Runtime

Websites (advanced)

Versioned integration records and redacted progress/error logs. Each control calls the real backend; enabling, grants, and manifest linking require confirmation.

Permission mode (websites)

Restricted is the default. Unrestricted only pre-authorizes routine read-only work inside the scopes you choose; it never bypasses confirmation, hard-deny rules, audit, or limits. Mode is durable policy state — page/model text can never change it.

Actions (advanced)

Packet 8F typed actions. Preview always; execute only after reviewing the exact preview and confirming (sending/posting/purchasing/deleting/account/system always need confirmation). Every result is the real backend typed state.
