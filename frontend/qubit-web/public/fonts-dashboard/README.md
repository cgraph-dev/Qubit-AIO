# Dashboard webfonts

Inter (400–800) and Rajdhani Bold (700) are the unmodified WOFF2 subset files served by Google Fonts, with their SIL Open Font License 1.1 texts alongside them. The dashboard loads only the subsets needed for the displayed characters.
