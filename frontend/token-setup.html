Copy the dashboard token from the Qubit PC
(the webui.token value in ~/.config/qubit-voicebridge/voice.yaml).
It is stored only in this browser's localStorage.

Pairing steps
  1. On the Qubit PC, open ~/.config/qubit-voicebridge/voice.yaml and copy the webui.token value.
  2. Paste it below and choose Save & test. The bridge checks the token before it is saved.
  3. If your previous token worked, it is kept until the new one is accepted.
