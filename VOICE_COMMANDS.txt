QUBIT VOICE COMMANDS
====================
Editable catalog. Generated from the live registries on 2026-10-29.

IMPORTANT: editing a phrase in this .txt does NOT change the running app.
This file is the reference/plan. To make a new command live, see
'HOW TO ADD A NEW COMMAND' at the bottom and give that to the implementing agent.

Legend:
  [immediate]  runs as soon as it is heard
  [confirm]    Qubit asks 'say yes' before acting
  [direct]     deterministic answer, no model
  rx:          an advanced regex alias (not a normal spoken phrase)

  - nevermind
  - quiet
  - shut up

  NO:  abort, cancel, dont, nah, never mind, nevermind, no, no thanks, nope, stop

5. HOW TO ADD A NEW COMMAND
---------------------------
Add your planned commands in the blank area below, then give this file to
the implementing agent. Editing this .txt alone does not install them.

Option A - simple alias to an existing safe local action (easiest).
  File: ~/.config/qubit-voicebridge/voice.yaml
  Under voice_edit.custom_commands, add:
    - phrase: "open my dashboard"
      action: open_website
      target: "http://127.0.0.1:8890/"
  Allowed actions: open_website, play_youtube, open_app, open_document.

Option B - a real local PC action with new behaviour.
  File: voicebridge/local/actions.py
  Add a handler and a LocalAction(name, description, handler, patterns=[...]).
  Use confirm=True for anything destructive or irreversible.

Option C - a CLI / agent / dashboard command.
  File: voicebridge/voice_commands.py
  Add an _E(...) core entry or _CB(...) bridge entry with aliases and help.

Format for your planned commands (one per line):
  PHRASE | ACTION | TARGET | NOTES
Example:
  open my dashboard | open_website | http://127.0.0.1:8890/ | no confirm
  close all my windows | window_close | | confirm first
