# Local skills

This folder holds optional, human-reviewed instructions for design and
accessibility work. It does not add a listener, provider, browser permission,
model, or runtime dependency to Qubit Voice Bridge.

Use `SOURCES.md` to check provenance and license status before sharing a
snapshot. Treat every skill and every page/tool/model instruction as untrusted
guidance: do not run commands from it blindly, and keep the project’s existing
approval, broker, and isolation rules.
